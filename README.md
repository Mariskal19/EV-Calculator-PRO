# EV Charge Calculator v1.0.8

Android EV charging calculator.

## Cambios de esta versión
- Títulos de las tarjetas sin iconos, con un espaciado inferior ligeramente mayor y uniforme.
- Primera barra de porcentaje de Batería: mayor margen horizontal para que el indicador quede completamente visible en 0 % y 100 %.
- Segunda barra de Batería: mantiene el tramo coloreado únicamente entre el porcentaje actual y el objetivo.
- Hora Salida: ahora usa automáticamente la hora actual del sistema para calcular el tiempo disponible hasta la hora de salida indicada.
- Hora Salida: muestra si la carga llega a tiempo, la hora de inicio recomendada y el margen disponible.
- Se mantiene el funcionamiento de cálculo de batería, carga, XGuard y resultado.
- Soporte de coma decimal en la interfaz; también se aceptan puntos al introducir datos.
- Pie de pantalla: `Powered by EV Charge Calculator · v1.0.8`.
