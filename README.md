# EV Charge Calculator v1.0.7

Android EV charging calculator.

## Cambios de esta versión
- Títulos de las tarjetas limpios, sin iconos, manteniendo el espaciado uniforme.
- Batería: los círculos de las barras de porcentaje quedan completamente visibles en 0 % y 100 %.
- Segunda barra de Batería: solo se colorea el tramo comprendido entre el porcentaje actual y el objetivo; las zonas anterior y posterior mantienen el color de fondo de la barra.
- Se mantiene el funcionamiento de cálculo de batería, carga, XGuard, resultado y hora de salida.
- Soporte de coma decimal en la interfaz; también se aceptan puntos al introducir datos.
- Pie de pantalla: `Powered by EV Charge Calculator · v1.0.7`.
