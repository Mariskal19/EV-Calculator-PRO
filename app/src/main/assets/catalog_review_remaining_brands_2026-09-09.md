# Revisión catálogo ES 2024–2026 — marcas restantes

Fecha: 2026-09-09

Objetivo: revisar las 17 marcas que quedaban después de XPeng y MINI, respetando la regla **MERCADO → MARCA → MODELO → AÑO/PERÍODO → VERSIÓN → CONFIGURACIÓN TÉCNICA**.

## Resultado de la pasada

Se ha revisado la cobertura existente y se han separado tres estados:

- **OK / cobertura razonable:** la marca ya tiene varias configuraciones y no se añaden datos dudosos solo por completar volumen.
- **REVISAR:** existen indicios claros de modelos/versiones que merecen una segunda pasada específica antes de incorporarlos.
- **OMISIÓN CLARA:** hay un modelo/configuración que no debería quedar fuera y dispone de datos suficientemente contrastables para una siguiente incorporación.

## Criterio aplicado

No se han añadido configuraciones únicamente para aumentar el número de coches. Cuando una cifra histórica, una fecha de llegada a España o una configuración concreta no queda suficientemente acreditada, se deja como **REVISAR** para no contaminar el catálogo.
